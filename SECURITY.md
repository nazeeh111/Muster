# Security and privacy

Muster runs a bounded scheduling model in a browser worker. It does not contact volunteers, upload schedules or call external APIs. Imported text is rendered as text, input sizes are bounded, and formula-like CSV cells are prefixed for spreadsheet safety.

Local storage and exported files may contain personal information. Browser storage is not an encrypted vault, and anyone with access to the browser profile may be able to read it. Clear or export data using your browser's controls and your organization's procedures. Do not publish real schedules as issues or fixtures.

For a suspected vulnerability, use this repository's private vulnerability reporting when available. Submit only synthetic reproductions; do not include private schedules, passwords or credentials. No comprehensive security certification is claimed.
