# Contributing

Run `npm test` with Node 22 or later. Serve the directory and exercise the affected browser workflow. Keep scheduling inputs synthetic in tests and issues.

Changes to the solver need a small independently enumerated counterexample, including simultaneous positions and locks where relevant. Do not broaden the model's promises through UI wording alone. Preserve existing work, input-validation behavior, and export compatibility deliberately.

A bug report should include the version/commit, browser or Node version, expected/observed behavior and a minimal synthetic project. Do not attach real volunteer schedules, contact details or other private data.
